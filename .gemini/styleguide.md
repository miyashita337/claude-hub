# Gemini Code Assist Style Guide

このリポジトリ（claude-hub = セッション実行基盤）のレビュー指針。

## 言語

- レビューコメントは**日本語**で記述してください。

## 重点チェック項目

- **TypeScript / bun 品質**: `any` の使用禁止。外部入力にはランタイムバリデーションを行っているか
- **セッションのライフサイクル**: 起動・停止・reap の各経路で worktree / tmux セッション / 子プロセスを取り残していないか
- **競合**: `sessions.db` への並行書き込み、tmux セッション名・ブランチ名の衝突を招かないか
- **不変条件**: 並列上限（`MAX_SESSIONS`）やキューの制約を壊していないか
- **サイレントフォールバック禁止**: エラーを握りつぶして「動いている風」にしていないか。失敗は必ず伝播またはログ化されているか
- **機密**: token のハードコード、`.env*` の誤コミット、ログへの token 出力

## ノイズ抑制

- typo / スタイルのみの nit は省略してください
- 既存コードと同等レベルの軽微な指摘は省略してください
- 指摘には `must` / `should` / `nit` の分類を明記してください

## 無視

- `.worktrees/**` 配下（worktree 作業ディレクトリ）
- `*.db`（SQLite 実体）
